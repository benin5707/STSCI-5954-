# 1. Add K-means candidate comparisons and final selected model：

This adds two analysis packages:
1. Nine Candidate Configurations: compares three data representations (original standardized features, PCA80, and PCA90) using K-means with k = 5, 6, and 7. Includes elbow diagnostics, PCA results, validation metrics, and stability checks.
2. Final Selected Model: uses the original nine standardized audio features with K-means and six clusters, without PCA.
Both packages include READMEs, organized source code, data, results, figures, saved models, and reproduction instructions.
